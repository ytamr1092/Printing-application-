# طباعة — PrintPilot Smart

تطبيق Expo/React Native عربي أولًا لإدارة ملفات PDF والطباعة محليًا من الهاتف، مع دعم الإنجليزية، الوضعين الفاتح والداكن، والمعاينات المنفصلة.

## ما يعمل حاليًا

- دمج ملفات PDF محليًا.
- تحويل الصور إلى PDF وحفظ الناتج ومشاركته.
- استخراج صور JPEG وPNG المضمنة في PDF في الحالات المدعومة.
- ترقيم PDF بنطاقات وفردي/زوجي وأرقام عربية هندية أو رومانية.
- إعادة ترتيب صفحات PDF وحذفها وتدويرها.
- معاينات مستقلة للدمج والتحويل والاستخراج والترقيم والطباعة وبطاقة الهوية.
- إعدادات الطباعة: الورق، الوزن، الاتجاه، الألوان، الوجهين، الحافة، النسخ والملاءمة.
- إنشاء PDF لبطاقة هوية من الوجهين.
- حفظ الإعدادات وسجل العمليات محليًا، مع نسخ احتياطي JSON واستعادته.
- دعم فحص اتصال الشبكة بطابعة/سكانر Kyocera.

## حدود معروفة

- زر المسح من Kyocera يتحقق من الاتصال ويجهز المسار، لكنه لا يستقبل الملف من الجهاز بعد. يلزم إعداد Scan-to-FTP/SMB أو TWAIN وبروتوكول استقبال مناسب.
- حماية PDF بكلمة مرور والمساعد الذكي ما زالا واجهتين تمهيديتين.
- المصادقة وقاعدة البيانات موجودتان كبنية أساسية، لكن بيانات الملفات والعمليات محلية حاليًا ولا توجد مزامنة حسابات.
- استخراج الصور يعتمد على صور JPEG/PNG المضمنة ويمكن ألا يغطي كل بنى PDF المعقدة.
- لم يتم تضمين APK داخل المستودع؛ يبنى عبر EAS عند الحاجة.

## التشغيل المحلي

المتطلبات: Node.js 22، وpnpm 9، وبيئة Expo.

```bash
pnpm install --frozen-lockfile
cp .env.example .env
pnpm check
pnpm test
pnpm lint
pnpm dev
```

`pnpm dev` يشغل خادم tRPC وMetro Web معًا. لا تضع أسرارًا حقيقية في المستودع أو في متغيرات `EXPO_PUBLIC_*` إلا إذا كانت مصممة للنشر العام.

## بناء Android

لإنشاء APK تجريبي عبر EAS:

```bash
npx eas login
npx eas build --platform android --profile preview
```

إعداد `preview` ينتج APK داخليًا، بينما إعداد `production` ينتج Android App Bundle للنشر.

## الفحوص

الفحوص المطلوبة قبل الدمج:

```bash
pnpm check
pnpm test
pnpm lint
```

اختبار المصادقة الموجود متجاوز عمدًا إلى أن تكتمل مصادقة المستخدم الفعلية.

## البنية المختصرة

- `app/`: شاشات Expo Router.
- `shared/`: منطق قابل للاختبار للطباعة والملفات والإعدادات.
- `server/`: خادم Express/tRPC وبنية OAuth/قاعدة البيانات.
- `drizzle/`: مخطط وترحيلات MySQL.
- `tests/`: اختبارات Vitest.
- `assets/`: الأيقونات وموارد التطبيق.
